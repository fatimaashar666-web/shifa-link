## Approved image strategies

1. **Original ShifaLink photography or commissioned illustrations** — preferred
2. **Properly licensed stock images** — document license, usage rights, and attribution here before use
3. **Provider-uploaded profile images** — only after consent and verification by admin
4. **Sanity image assets** — for approved public editorial images only
5. **Private storage** — for sensitive patient-uploaded images and scans

---

## Image licensing checklist (before adding any asset)

- [ ] Source is documented (website URL or vendor name)
- [ ] License type is confirmed in writing (not assumed)
- [ ] Attribution requirements are noted
- [ ] Usage scope matches the license (web, commercial, etc.)
- [ ] No Practo, Getty, Shutterstock, or other restricted assets hotlinked
- [ ] Demo images use clearly synthetic/placeholder data — no real patient photos
